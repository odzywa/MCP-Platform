Zarejestruj External MCP Server

Po rejestracji platforma automatycznie sprawdzi status i odkryje tools przez MCP protocol.

Jak używać z Continue / OpenWebUI?

Po wykryciu tools, skopiuj endpoint URL i dodaj go do konfiguracji klienta MCP:

# Continue (config.json)
{
  "mcpServers": [
    {
      "name": "My External MCP",
      "transport": {
        "type": "http",
        "url": "http://hostname:8080/mcp"
      }
    }
  ]
}
