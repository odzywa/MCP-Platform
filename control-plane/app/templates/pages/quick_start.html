🔒 Ograniczenia dostępu

Określ dokładnie co AI może robić. Szczególnie ważne przy pełnym dostępie ${{ '{' }}*args}.
Zostaw puste = brak ograniczeń na prefix.
Wpisz np. oc get → AI może TYLKO wywoływać oc get ... — nie może oc delete, oc apply itp.
Komendy zaczynające się od tych prefiksów będą zablokowane.
Np. kubectl delete blokuje kubectl delete pod xyz, kubectl delete -f ... itp.

            ❓ Co mogę tutaj zaimportować?
          


          
          

            
✅ Działa — Platform Package JSON

            

              Plik JSON opisujący tools do uruchomienia wewnątrz platformy — stworzony przez Package Generator, wyeksportowany z innego serwera lub pobrany z repo który ma taki plik.
              
Poznasz go po polach: "tools", "runtime_class", "policy"
            

          


          
          

            
❌ Nie działa — repo z kodem aplikacji

            

              Repo GitHub z kodem C#, Python, Node.js itp. (np. ustabar/sql-mcp) to gotowa aplikacja serwera MCP —
              nie plik konfiguracji. Platforma nie kompiluje ani nie uruchamia obcego kodu bezpośrednio.

          📄 Jak wygląda format Package JSON?
          

            Package JSON to plik definiujący kompletny serwer MCP. Możesz go dostać przez:

            • Eksport istniejącego serwera → otwórz runtime → sekcja Lifecycle → "Eksportuj jako Package JSON"

            • GitHub → szukaj plików mcp-package.json lub *-package.json

            • Package Generator → utwórz własny
